# Сервис для бронирования билетов на мероприятия

## Назначение

Консольное приложение для бронирования билетов на мероприятия
(театр, кино, выставки и т.д.): хранение информации о мероприятиях
с датой и временем их проведения, возможность бронировать
и отменять бронирование.

## Целевая аудитория

Люди, желающие разнообразить свой досуг посещением мероприятий:
дети с родителями, подростки, взрослые и пожилые люди.

## Предметная область

Управление бронированием билетов: создание брони, отмена брони,
проверка доступности мест на мероприятие, расчет стоимости билетов.

## Основные сущности

- пользователь (имя, почта, телефон, дата рождения (опционально), пароль)
- мероприятие (название, время проведения, место проведения,
  количество мест, цена билета, возрастные ограничения)
- бронирование (мероприятие, пользователь, количество билетов, статус)

## Основные функции

- `is_seats_available` — проверка наличия свободных мест на мероприятие;
- `get_booking_status` — вывод текстового статуса бронирования;
- `calculate_total_price` — расчет итоговой стоимости билетов.

## План развития

На следующих этапах планируется:

- переход от одиночных переменных к коллекциям (списки, словари);
- переход к объектно-ориентированной модели (классы Event, User, Booking);
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения и настройка CI/CD.
